# 个人决策团 · Personal Council

在 Mac 上运行的本地个人系统：每日任务、习惯记录、事件式编年史、月报、Markdown 笔记和资产记录。Python 标准库后端、SQLite、原生 JavaScript 前端；默认只监听 `127.0.0.1:8765`。

此仓库仅包含程序和空白初始结构，不包含个人笔记、资产、数据库或云盘备份。

## 换电脑恢复

完整图文式操作步骤见 **[RECOVERY.md](RECOVERY.md)**。

1. 下载并解压本仓库。
2. 从 iCloud Drive 的“个人决策团备份”下载最近的 `council-…zip`。
3. 先双击 **恢复数据.command**，把备份拖入窗口，等到校验和恢复成功。
4. 双击 **启动个人决策团.command**，打开 http://127.0.0.1:8765/。
5. 登录 iCloud 后双击 **配置云盘备份.command**，重启服务并检查设置页的备份状态。

需要 Python 3.9 或以上。尚未恢复就启动，会创建空白数据；恢复工具会拒绝覆盖已有数据，请改在一份全新解压的程序目录里恢复。

## 代码与数据

- 程序在本机运行，数据默认在 `data/personal.sqlite3`；可使用 `python3 server.py --data /本地数据目录` 指定。
- SQLite 在线备份包含正式、测试两个空间和保存快照；先校验再写入配置的云盘文件夹。
- 默认数据目录放在本机，云盘只接收不可变的完整备份包，不直接同步正在使用的数据库。
- 网页设置显示的是文件夹写入结果，无法确认 iCloud 的上传完成状态。
- `8766` 只跳转到 `8765`；开发副本请使用 `8877` 和独立数据目录。
- 只有已保存记录进入备份；浏览器草稿、外观选择和 Obsidian 外部附件不包含。

## 持续更新

修改前阅读 AGENTS.md。先在独立数据副本测试，再更新程序。新版本发布后把通过检查的代码同步到本仓库；备份不能替代代码版本保存。不要提交 `data/`、`seed.json`、`backups/`、数据库或任何带个人内容的导出文件。


未加工信息原料：位于档案库并可侧栏置顶，左侧按日期快速保存原话（⌘/Ctrl+Enter；普通 Enter 换行），右侧按月从新到旧连续回看、搜索正文及手动标签、导出 Markdown。无标题要求，不自动总结或分类，不加入任务／习惯／编年史完成进度。条目支持编辑、回收站恢复，长原文可展开。草稿仅在浏览器按空间、功能根 ID、日期隔离保存；已保存记录使用 notes 的稳定 ID、folder、date、body、tags，module=materials 路由，无新 schema 字段。原文 body 原样保存和导出，现有数据库备份／恢复包含该模块。

原料录入界面简化为日期、正文框与确认按钮，移除录入提示、标签输入和左侧重复列表；确认后在右侧对应月份显示。保留原文、草稿、编辑标签和导出能力。

原料“查看这天”进入单日完整阅读页，按日期隔离并保留返回与编辑／移除功能；月档案仍采用摘要。今日新增半宽原料输入卡片，支持拖动与布局配置，使用首页所选日期，和原料页共享该日期的浏览器草稿，保存为同一份 notes。layout 允许新增 materials ID，无记录结构迁移；旧布局通过 API 只追加卡片，保留已有位置与宽度。回退旧程序需同时恢复变更前布局或备份。

习惯新增记录方式：计划打卡／随手记录。optional 是规则版本中的可选布尔字段（缺省 false），新规则按生效日期切换，过去版本与打卡不变。随手习惯在记录库保留，首页（包括已完成折叠）不展示，scheduled 返回 false，不计每日进度；不要求星期安排，空白统计为 unrecorded，不计未完成，不在数量图伪造零。仍保留已有的明确数量合计、记录日均和日历日均。支持三种记录类型；回滚旧程序时应恢复发布前备份，避免旧版忽略 optional。

## macOS 后台常驻
建议把程序保存在 `~/Library/Application Support/个人决策团`，避免后台进程读取文稿目录时触发 macOS 权限限制。双击“启用后台常驻.command”注册当前用户的登录启动服务；退出后自动恢复，仅监听本机 8765。普通“启动个人决策团.command”会唤起已有后台服务，不再绑定启动窗口。电脑关机、注销或休眠时服务不能提供访问，登录／唤醒后恢复。停用可在该目录运行 `python3 background_service.py --disable`，不会删除数据。

重要日子：档案库下独立 dates 模块并置顶侧栏。支持公历／农历、单次／每周／每月／每年与自定义周期、提前 0—365 天的首页提醒；提醒关闭仅针对本次临近日期，不影响当天展示或次年提醒，不计任务进度。支持暂停、编辑、移除及回收站恢复。日期范围 1901—2099 年，闰月缺失及日期缺失的重复规则可在特殊日期规则中设置。节假日日期由用户填写，不自动导入放假安排。仅网站首页内提醒，没有系统推送。农历库离线内置、MIT 许可，来源与固定版本记录见 static/vendor/lunar-SOURCE.md；2027 年春节等边界已按香港天文台对照表核验。

重要日子选日改为双历可点击月历：公历数字为主、下方农历；农历以正月／冬月／腊月、初一／廿三等名称为主、下方公历，闰月仅显示真实存在的月份。重复支持每周、每月、每年与每 N 天／周／月／年（1—999）；按原始日期锚定，短月不累积漂移。农历月份按实际月序推进，闰月计一个月，年重复仍遵循原闰月策略。


## 花销初版
财政部的“花销”记录人民币消费与关联退款；今日卡片可直接录入。必要性（必要／可选／待判断）和用途分别保存，用途可增建、改名、停用。明细按实际日期连续回顾，可按月份、必要性、用途和内容筛选，导出本月 CSV。月度总预算与可选支出额度独立设置，留空表示未设预算；不会替用户猜测金额或预算。
周期账单支持月付／年付，只在用户确认实际扣款后生成消费并推进一期；未确认账单不计入支出。月底、闰年均从原日期锚定，不累积漂移。退款必须关联原消费，累计不超过原额，按到账月份抵减净支出。移除进入回收站，可恢复。花销与国库余额相互独立，不自动扣余额，不接银行、自动支付或外部 AI；初版只用人民币。


首页紧凑排列：半宽卡片按已保存的顺序依次进入较短的一列，保持统一间距；全宽卡片位于前面两列的下方，随后重新分列。卡片内容增减、展开收起和窗口变化时自动重新测量；窄窗口沿用单列。保留现有拖拽、宽度、显示设置和全部记录，不写入新的数据字段。

新增花销默认选择“必要”，包括首页、账本快捷录入和新增周期账单；用户可手动改成可选／待判断。已保存记录、已有账单和未提交草稿中的选择保留，成功保存后下一笔恢复默认必要。仅前端默认值调整，无数据迁移。


## 花销细分类与月度对比
分类可逐层自建，最多五级；例如餐饮 → 咖啡，餐饮 → 正餐 → 早餐／午餐／晚餐。首页、账本录入、编辑和周期账单均可选到任意一级，细分类默认收起且可不选。右上角更多菜单 → 管理分类，选择上级后新增，也可改名或停用。已有分类的上级保留，停用分支不出现在新选择中，其历史记录仍可筛选和统计。旧消费保持原分类，不根据标题自动细分。
“分类统计”按所选分类及其全部下级、必要性汇总，支持近 6／12 个月的柱状图与具体金额，点击月份可回顾该月。未记录月份明确标为未记录；退款按实际到账月份抵减净支出。选择父分类不会重复计数，原来只选父分类的消费仍保留为未细分金额；导出 CSV 包含完整分类路径。


## 手机随手记
独立手机网页可提交花销、任务、编年史、想法、原料与习惯。电脑侧栏“手机收件箱”确认后直接入库；手机仅同步录入配置和提交状态，不读取完整个人数据库。网络中断时保留待发送记录，Mac 离线时由私人中转站暂存。部署、固定接口 v1、兼容与恢复说明见 [MOBILE.md](MOBILE.md)。

## 个人推进台
首页选择领域开始推进，“此时正在做”记录本次用时，支持暂停、结束、切换、补记与修正。侧栏“个人推进台”可快速列问题，整理下一步，追加尝试与结论；领域资料继续留在原空间。计时结束不会自动解决问题，每日任务继续用于需要安排到某天的事情。手机随手记新增问题／推进进展，仍由电脑确认入库。
误触开始时可点“取消本次计时”，该时段不计入统计；如需找回，在“投入记录”中恢复。
